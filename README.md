# 2026 전주대학교 대동제 및 밤샘 해커톤 로그 데이터 분석

## 1. 프로젝트 소개

본 프로젝트는 Python의 정규표현식을 활용하여 2026 전주대학교 대동제 및 밤샘 해커톤 통합 운영 로그 데이터에서 필요한 정보를 자동으로 추출하는 프로그램입니다.

## 2. 개발 환경

- 개발 언어: Python
- 개발 도구: Visual Studio Code
- 사용 라이브러리: re (정규표현식)

## 3. 주요 기능

1. **유효한 이메일 추출**
   - 문서 전체에서 올바른 형식의 이메일 주소 추출
   - 잘못된 도메인 형식 제외

2. **휴대폰 번호 추출**
   - 010으로 시작하는 휴대폰 번호 추출
   - 하이픈(-), 마침표(.), 공백 구분자 허용
   - 지역번호 및 자릿수가 부족한 번호 제외

3. **학번 및 학과 추출**
   - 202로 시작하는 9자리 학번 추출
   - 학번과 학과명을 튜플 형태로 분리

4. **GitHub 저장소 및 유효 쿠폰 추출**
   - GitHub 저장소 URL 추출
   - GitLab 주소 제외
   - 2026년도 발급 쿠폰 코드 추출

5. **부스별 매출 분석**
   - 각 부스의 총 매출액 추출
   - 카드 및 현금 세부 내역 제외
   - 전체 매출 합계 계산

## 4. 사용 기술

- `re.findall()`: 정규표현식에 일치하는 모든 데이터 추출
- 정규표현식 패턴: 이메일, 전화번호, 학번, URL, 쿠폰 및 매출 데이터 검색
- `int()`: 문자열을 정수형으로 변환
- `sum()`: 전체 매출액 합산

## 5. 실행 방법

1. 프로젝트 파일을 다운로드하거나 GitHub에서 Clone합니다.
2. `festival_log.txt` 파일을 프로젝트 폴더에 배치합니다.
3. 터미널에서 다음 명령어를 실행합니다.

```
python main.py
```
